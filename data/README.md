# Data boundary

**No authentic institutional, commercial, contact or proposal records are stored in this public GitHub repository.**

- Public repository: schema, generic documentation, and approved/synthetic fixtures only.
- Private runtime/team store: approved tier amounts and entitlements, authentic contacts, source presentations, needs inventories, research dossiers and generated proposals.
- Initial E1 source: 2026 PPTX documents (private, source-verified but needs labeled provisional); 2025 PDF historical only.
- 2025/2026 achievement claims were confirmed for public use for a 2026/2027 proposal but must retain original historical cycle labels.
- Annual budget figures are excluded from the AI knowledge/recommendation pipeline.
- See `specs/knowledge_contracts.md` and `docs/PRIVACY_AND_DATA_HANDLING.md`.

The SQLite file is ignored. E1 is a planning/data-governance milestone; a protected datastore has not been implemented.
